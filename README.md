- Skills

- Education
- Achievements
- Contact

## Deploy to GitHub Pages

This is a static site (`index.html` is the only file needed). To host it at `https://<your-username>.github.io/portfolio/`:

```bash
# 1. Create a repo on GitHub named "portfolio" (or use an existing one)
#    https://github.com/new

# 2. Push this folder up
git remote add origin https://github.com/<your-username>/portfolio.git
git add .
git commit -m "Add interactive portfolio"
git branch -M main
git push -u origin main
```

Then enable Pages: **Settings → Pages → Source → Deploy from a branch → `main` → `/ (root)` → Save.**

Your site will be live at `https://<your-username>.github.io/portfolio/` in a minute or two.

### Custom domain (optional)
Your GitHub username also works: you can set the page URL to `https://<your-username>.github.io` by publishing from a repo named `<your-username>.github.io`. Rename the repo or publish from the repo root accordingly.
